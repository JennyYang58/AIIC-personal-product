# 智研星云 · AI 驱动的下一代科研经营体系

> **Slogan：让科研，自己跑起来。**
> 副标题：AI 驱动的下一代科研经营体系
>
> 面向大学高校与各类科研院所，覆盖「入门—文献—复现—创新—发表—招生—调度—经费—日程」的科研全生命周期，让 AI 真正参与科研、经营科研。

---

## 一、产品概览

| 项 | 内容 |
|---|---|
| 产品名 | 智研星云（ZhiResearch Nebula） |
| 定位 | 面向高校、科研院所的 **AI 驱动一站式科研经营平台**：既是个人科研者的「AI 科研搭档」，也是课题组与机构的「科研 ERP + 决策驾驶舱」 |
| 核心理念 | 把企业经营方法论引入科研管理：科研也是一门「经营」——**定目标（选题）→ 配资源（人/钱/设备）→ 抓执行（实验/写作）→ 看结果（发表/结题）→ 复盘迭代**，AI 全程参与闭环 |
| 愿景 | 让不同类型的科研机构都能发挥最大优势，形成可积累、可复利的科研竞争力，助力中国科研更上一层楼 |
| 用户 | 本科生 / 硕博研究生（新手科研者）、导师 / PI、课题组、院系与科研处、院所管理者 |

### 1.1 与智创星云的对标设计逻辑

智创星云用「ERP 内核 + 创意工厂 + 投放托管 + 增长飞轮 + Claw 智能体中枢」让生意自己跑起来；智研星云用完全同构的体系让科研自己跑起来：

| 智创星云（生意经营） | 智研星云（科研经营） | 对应痛点 |
|---|---|---|
| 星云 ERP：企业经营的操作内核，十大模块，AI 经营协同（发现问题→理解原因→定位对象→推动处理→结果反馈） | **研云 ERP**：科研经营的操作内核，十大模块，AI 科研协同，从「人找问题」到「问题主动找人」 | 痛点 5/6/7/8 |
| 星云 Studio：AI 图像/视频/数字人/音频，一站式素材全链路 | **研云 Studio**：AI 写作/图表/翻译/汇报 + 科研启航学院，「从一篇文献到一篇论文」的创作全链路 | 痛点 1 |
| 星云 广告：AI 全托管投放，店铺授权→创建活动→开启托管→自动执行→查看效果→复盘优化 | **研云投稿**：发表全托管，成果整理→期刊诊断→开启托管→自动适配→状态追踪→复盘转投 | 痛点 4（发表侧） |
| 星云 GEO：意图词诊断、机会挖掘、品牌增长飞轮 | **研云慧眼**：文献情报中枢 + 创新 Gap 诊断、选题评分、科研增长飞轮 | 痛点 2/4（创新侧） |
| （无直接对应，素材链路的科研版） | **研云 Lab**：零代码复现引擎，「一篇论文 → 一组结果」的实验全链路 | 痛点 3 |
| （招生无对应，ERP 客服/绩效的科研版） | **研云 Match**：套磁信解析 + 师生双向匹配引擎 | 痛点 5 |
| 星云 Claw：IDE 创作中心 + 办公室专家团队 + 任务通知 + 扩展空间 + 星云生态 | **研云 Claw**：科研 Agent 中枢 + 科研专家团队 + 科研生态连接 | 全部痛点的 AI 底座 |
| 深入经营 / 参与决策 / 推动执行 / 走向全球 | **深入科研 / 参与决策 / 推动执行 / 走向世界（顶刊顶会）** | 愿景 |

### 1.2 三句话讲清产品

1. **对个人**：从「不知道怎么开始」到「AI 教我开始、帮我读文献、替我跑实验、陪我写论文、为我选期刊」。
2. **对导师**：从「凭经验管团队」到「AI 帮我看进度、配任务、管经费、筛学生、排日程」，组会前一切尽在驾驶舱。
3. **对机构**：从「科研处手工统计报表」到「科研驾驶舱 + 智能预警 + 学科评估数据自动就绪」，形成机构级科研竞争力。

## 五、六大产品详细设计

### 5.1 研云 ERP —— 科研经营的操作内核

**口号：让课题组像一家好公司一样运转。**

#### 十大核心业务模块

| 模块 | 核心功能 |
|---|---|
| 1. 项目管理 | 申报日历 / 立项评审 / 节点里程碑 / 结题自动化 |
| 2. 成果管理 | 论文·专利·软著·奖励台账 / 机构成果库自动认领 / 学科评估指标归集 |
| 3. 经费管理 | 预算编制 / 执行监控 / 报销助手 / 结题决算 |
| 4. 人员管理 | 课题组成员 / 能力画像矩阵 / 成长档案 / 离组交接 |
| 5. 招生管理 | 套磁收件箱 / 匹配评分 / 面试安排 / 名额联动（对接研云 Match） |
| 6. 日程管理 | 组会·讲座·会议·申报截止统一日历 / AI 排期（详见 5.1.3） |
| 7. 文献资产 | 机构文献库 / 组内知识沉淀 / 与研云慧眼联通 |
| 8. 实验与设备 | 设备预约 / 耗材库存 / 实验记录本（ELN）/ 安全准入 |
| 9. 伦理与合规 | 伦理审查流程 / 学术诚信检测 / AIGC 使用披露 / 利益冲突申报 |
| 10. 统计分析 | 科研驾驶舱 / 主题报表 / 预警支援（机构·院系·课题组三级） |

#### 5.1.1 AI 科研协同：从发现到行动（对标星云 ERP 的经营协同闭环）

**发现问题（01）→ 理解原因（02）→ 定位对象（03）→ 推动处理（04）→ 结果反馈（05）**

> 从「人找问题」，到「问题主动找人」。每一轮反馈，都进入下一轮判断与协同。

典型场景：
- **进度类**：某项目结题还剩 3 个月、关键实验只完成 40% → AI 分析是人员负载过高还是技术路线卡壳 → 定位到负责人与可用支援 → 推送调配建议 → 跟踪是否回归正常。
- **经费类**：年底执行率仅 55%、某科目超支风险 → 解释原因（劳务费比例限制/采购周期）→ 定位到项目与经办人 → 生成合规支出建议清单 → 跟踪执行率回升。
- **人员类**：某学生连续 4 周无实验记录、文献阅读骤降 → 结合课程表判断是否考试周 → 温和提醒导师关注 → 记录沟通结果。

三个价值锚点（沿用智创星云语言体系）：
- **看得清** —— 关键科研信号（进度、经费、投稿、成员状态）第一时间发现；
- **算得准** —— 结合科研规则（基金管理办法、学科规律）解释原因；
- **动得快** —— 定位到人、钱、事，协同跟进处理。

#### 5.1.2 课题组智能调度中心（痛点 6）

- **成员能力画像**：从系统内真实行为（文献笔记、实验记录、写作贡献、代码提交）+ 简历自动生成技能矩阵（方向 × 工具 × 熟练度 × 意愿），杜绝「简历自吹」。
- **项目拆解与任务推荐**：AI 把项目拆成任务包（调研/实验/写作/报账），按「能力匹配 × 当前负载 × 发展意愿」三维推荐分配，导师一键确认或调整。
- **负载热力图**：一屏看全组每个人的任务量、deadline、课程/考试/答辩冲突，红黄绿预警，避免「能者过载、新人闲置」。
- **公平与成长算法**：高价值任务与「打杂」任务轮换配比；为每个学生自动生成「下一段成长建议」（该学的方法、该投的会议、该补的技能）。
- **组会自动化**：AI 汇总各成员周进展 → 生成组会 agenda 与上会材料 → 会后生成纪要与行动项（Action Items 自动进入任务系统）。

#### 5.1.3 科研日程与时间轴引擎（痛点 8）

- **全域日历**：课程表（教务对接）、组会、讲座论坛、学术会议、基金申报截止、审稿任务、项目节点、投稿状态事件，全部一屏。
- **申报日历**：国自然/社科基金/教育部/省市级项目的申报、中期、结题时间线自动订阅，倒计时提醒，AI 提前生成「申报材料准备清单」。
- **AI 日程优化**：自动检测冲突；为深度科研预留整块时间（Time Blocking）；出差与投稿截止、组会与课程智能联动调整。
- **三级视图**：个人日历 / 课题组日历（排组会不再群里接龙）/ 机构学术日历（全院讲座统一发布、AI 按研究方向推荐「值得听」）。
- **周计划与复盘**：每周日晚 AI 生成上周复盘 + 下周建议，向导师推送组内周报摘要。

#### 5.1.4 科研经费智能管家（痛点 7）

- **预算编制助手**：按项目类型（国自然/省市级/横向/校级）自动套用科目体系与比例红线（直接/间接费用、劳务费上限等），编制即合规。
- **执行监控**：单项目/多项目/全组经费卡合并视图；执行率偏差预警、科目挪用风险提示、结题前「突击花钱」与「执行率不达标」双向预警。
- **报销助手**：发票 OCR 识别、科目自动匹配、流程指引与退单原因解释（把财务制度变成「AI 客服」）。
- **决算与审计**：结题决算报告一键生成、全程留痕可审计，横向经费与纵向经费分账清晰。
- **合规规则引擎**：各基金委/部委管理办法内置为可更新规则库，政策变了系统先知道。

### 5.2 研云慧眼 —— 文献情报与创新发现引擎（痛点 2 + 4 创新侧）

**口号：让文献井井有条，让创新点主动敲门。**（对标星云 GEO）

#### 5.2.1 智能文献中枢（痛点 2）

- **一键汇聚**：PDF/DOI/arXiv 链接拖入即入库；知网、WoS、Scopus、谷歌学术插件一键收藏；Zotero/EndNote/Mendeley 库一键迁移（降低替换成本）。
- **AI 精读卡片**：每篇文献自动生成结构化卡片——研究问题 / 方法 / 数据 / 创新点 / 局限 / 「对我的课题有什么用」，中英对照，引用可溯源到原文页码。
- **课题知识图谱**：文献自动聚类成主题；引文网络可视化；「这个方向 5 年脉络」时间线一键生成；写综述时 AI 给出脉络框架与素材。
- **语义检索**：不用记关键词，用自然语言问「找近三年用联邦学习做医疗影像的、有开源代码的论文」。
- **情报订阅**：每日 arXiv/期刊增量按课题方向过滤推送；「本月我领域必读 10 篇」自动生成。
- **写作联动**：Word/Overleaf 插件插入引文，GB/T 7714、APA、IEEE 等格式一键切换，与研云 Studio 打通。

#### 5.2.2 创新发现与选题诊断（痛点 4 前半，对标 GEO 三大亮点）

对标星云 GEO 的「意图词诊断与机会挖掘」：

- **01 Gap 诊断与机会挖掘**：基于知识图谱分析「哪里人山人海、哪里还是空白」：方向拥挤度热力图、方法组合空白点、跨学科交叉机会（A 领域的方法 × B 领域的问题），并评估数据可得性与复现难度。
- **02 选题评分器**：输入一个 idea，AI 从新颖性 / 可行性 / 工作量 / 数据与算力需求 / 预期贡献打分，与近三年相似工作比对，避免「撞车」和「炒冷饭」。
- **03 头脑风暴 Copilot**：苏格拉底式提问帮新手把模糊兴趣收敛为可执行的研究问题（Research Question），生成 3 个递进方案（保底/进取/冒险）供导师把关。

#### 5.2.3 科研增长飞轮（对标 GEO 品牌增长飞轮）

**发现机会 → 创新验证 → 成果产出 → 影响力扩散 → 迭代优化**

> 每一轮反馈，都进入下一轮选题与探索，让课题组的研究持续增长。
> 沉淀三类资产：**知识资产**（文献库·实验记录）、**数据资产**（数据集·代码）、**声誉资产**（成果·学术影响）。

### 5.3 研云 Studio —— 科研启航与创作工厂（痛点 1）

**口号：让新手敢开始，让论文写得出。**（对标星云 Studio）

#### 5.3.1 科研启航学院（痛点 1：新手不知道怎么开始、怎么选工具）

- **AI 科研教练**：输入「专业 + 年级 + 兴趣 + 每周可投入时间」，生成个人版《科研入门路线图》：该看什么课、读哪 10 篇经典、用什么工具、12 周里程碑（像健身计划一样可执行）。
- **工具选型百科**：按场景给答案，不给罗列——「文献管理选什么（附 3 步上手教程）」「画机制图用什么」「统计不会编程用 SPSS 还是 JASP」「LaTeX 要不要学」。每个推荐附带理由、替代项、上手成本，并按用户真实水平分级。
- **第一个科研向导**：选题 → 文献 → 方法 → 实验 → 写作 → 投稿，全流程拆成打卡任务，配甘特图；每一步 AI 给示范 + 导师可检查。
- **学术规范课**：什么是抄袭/自我抄袭、如何正确引用、图像处理红线、作者贡献声明（CRediT），用案例教学，从第一天养成规范。

#### 5.3.2 AI 创作四件套（对标 Studio 的图像/视频/数字人/音频）

| 能力 | 说明 |
|---|---|
| **AI 写作** | IMRaD 逐节辅导与润色；中式英语改写；审稿意见 Response 生成；保持作者原意的「增强」而非「代写」（详见 9.3 学术红线） |
| **AI 图表** | 学术插图（机制图/流程图/数据图）生成与美化，符合期刊规范（分辨率/字号/色盲友好配色）；Graphical Abstract 一键生成 |
| **AI 翻译** | 学术中英互译，术语一致性检查，保留公式与引用 |
| **AI 汇报** | 论文 → 组会 PPT / 学术会议 Poster / 3 分钟答辩讲稿，一键多场景适配 |

#### 5.3.3 创作全链路（对标 Studio「一站式素材全链路」）

**01 一组数据 → 02 一张图 → 03 一篇初稿 → 04 一次汇报 → 05 一份投稿件**

> 一份实验结果，全程流转：从数据表自动出图、由图表联动生成初稿段落、再适配成组会 PPT 与投稿 PDF——改一处，全链路同步。

### 5.4 研云 Lab —— 零代码复现与实验引擎（痛点 3）

**口号：不会写代码，也能复现论文。**

#### 5.4.1 论文 → 实验全链路

1. **01 论文解析**：上传论文，AI 抽取算法流程、模型结构、超参数、数据集与评测指标，生成「可执行的方法说明书」；
2. **02 环境即开即用**：云端预置环境（Python/PyTorch/TensorFlow/R/MATLAB），免配置；GPU 容器按需拉起，用完即释放；
3. **03 AI 结对编程**：自然语言 → 代码生成；报错自动诊断与修复建议；逐行代码讲解（边跑边学，治好「代码恐惧症」）；
4. **04 一键复现模板库**：与 Papers with Code 类似的复现卡片社区，热门论文官方/用户共建「一键复现」，标注复现成功率与环境版本；
5. **05 实验记录自动化**：数据版本、代码版本、超参、指标、图表自动记录成实验台账，可回溯、可对比、可分享；
6. **06 复现报告**：与原文指标对比表 + 差异归因分析，一键生成（可作为课程作业、毕设章节、论文附录）。

#### 5.4.2 安全与算力

- 代码在隔离沙箱运行，防逃逸；机构可指定「数据不出校」的本地算力池；
- 融合机构 GPU 集群调度：闲时跑复现、忙时让路科研主任务；
- 学生实验数据自动归档进课题组数据资产库。

### 5.5 研云投稿 —— 智慧发表引擎（痛点 4 发表侧）

**口号：让发表更简单，让等待更短。**（对标星云广告「让广告经营更简单」）

#### 5.5.1 五大核心价值（对标星云广告五卡片）

| 价值 | 说明 |
|---|---|
| **1. 期刊全诊断** | 输入稿件，AI 从范围匹配度 / 影响因子与分区 / 审稿周期 / 接受率 / 版面费与 OA 政策 五维打分，输出「投稿梯度方案」（冲/稳/保） |
| **2. 智能策略** | 结合研究类型、时效性（热点窗口期）、作者履历与竞争情况，制定投稿顺序策略 |
| **3. 自动优化** | 目标期刊模板自动适配（格式/字数/参考文献）；Cover Letter 自动生成；投稿材料清单核对 |
| **4. 避坑预警** | 预警期刊（中科院预警名单）、掠夺性期刊、水刊识别；一稿多投红线提醒 |
| **5. 全链路洞察** | 投稿状态时间线（Submitted/Under Review/Major Revision…），各环节耗时 vs 该刊历史中位数，超期自动建议催稿 |

#### 5.5.2 发表六步流程（对标星云广告六步）

**成果整理 → 期刊诊断 → 开启托管 → 自动执行（格式适配/材料核对）→ 状态追踪 → 复盘优化**

> 从成稿到见刊，全程可见、可控、可追踪。

- **大修/小修响应**：AI 逐条解析审稿意见，生成回复框架与修改定位，标注「哪条必须补实验、哪条可以据理力争」；
- **被拒转投**：一键生成转投方案（结合审稿意见判断该补还是该换道），改稿建议自动带入下一轮；
- **发表复盘**：本轮投稿周期、返修轮次、录用期刊沉淀为课题组「发表经验库」，越用越准。

### 5.6 研云 Match —— 套磁筛选与师生双向匹配引擎（痛点 5）

**口号：让最合适的学生，遇见最合适的导师。**

#### 5.6.1 学生端（让好学生被看见）

- **AI 套磁信教练**：基于导师真实研究方向与近三年论文，帮学生生成「有内容、有针对性」的套磁信；模板化/群发式套磁会被提示优化（从源头减少导师端噪音）；
- **学生科研画像**：成绩单、项目经历、技能证书、开源贡献（GitHub/Gitee）、竞赛奖项、研究兴趣结构化成画像卡，学生自主授权范围。

#### 5.6.2 导师端（从海量邮件到精准名单）

- **套磁收件箱**：邮箱一键接入，AI 自动解析每封套磁信 → 提取关键信息（背景/技能/意向方向/可入学时间）→ 生成结构化档案；
- **真实性校验**：声称的论文/专利/项目与公开数据库交叉核验，标注「已验证/待核实/存疑」；
- **匹配度评分**：导师方向图谱 × 学生画像向量相似度 + 技能互补度 + 历届学生成才数据回learn（哪类背景的学生在组里发展最好）；
- **反噪音**：识别 AI 批量生成的千篇一律套磁信、夸大陈述，自动降权；
- **流程闭环**：感兴趣 → 面试安排 → 笔试/试做任务发放 → 结果记录 → 名额与 ERP 招生模块联动，全程留痕、公平可审计。

#### 5.6.3 合规内建

- 遵循《个人信息保护法》：学生明确授权后才向导师展示画像；数据仅用于招生匹配；到期自动删除；
- 匹配只做「排序与解释」，录取决策永远留给导师；算法可解释（为什么推荐/为什么不推荐）。

### 5.7 ★ 研云 Claw —— AI 科研智能体中枢（对标星云 Claw）

**口号：五大核心功能，让 AI 真正进入科研。**

| 功能 | 说明 |
|---|---|
| **01 IDE 创作中心** | 从一个需求出发，创建轻应用（如「组会签到+轮值表」）、Agent 专家、工作流（如「每周五自动汇总组内进展生成周报」）与技能，沉淀课题组可复用能力 |
| **02 科研专家团队** | 见下表，围绕科研目标按专业分工协同推进 |
| **03 任务及通知** | Agent 任务按计划运行，进度、待办与异常主动送达（消息推送至企业微信/钉钉/飞书/邮件），及时跟进结果 |
| **04 扩展空间** | 专家、技能、工作流与连接器按需获取调用；机构可发布自己的 Agent 到内部市场 |
| **05 科研生态** | 连接研云 ERP/慧眼/Studio/Lab/投稿/Match 与外部系统（文献数据库、期刊系统、教务财务），把 AI 能力落到真实科研动作 |

#### 科研专家团队（对标星云 Claw 八专家）

| Agent | 职责 |
|---|---|
| 科研大脑（PI 副驾） | 统筹全局：进度、风险、资源调配建议，组会前简报 |
| 文献情报专家 | 每日情报、Gap 分析、综述脉络、精读卡片 |
| 实验复现工程师 | 论文解析、代码生成、环境搭建、复现报告 |
| 论文写作教练 | 逐节辅导、润色、图表规范、查重预检 |
| 投稿策略顾问 | 期刊诊断、材料适配、审稿意见响应、转投方案 |
| 招生匹配官 | 套磁解析、画像核验、匹配排序、面试安排 |
| 经费财务专家 | 预算编制、执行预警、报销指引、决算生成 |
| 日程管家 | 日程优化、冲突检测、申报倒计时、周复盘 |

#### 最佳实践（对标星云 Claw 五步）

**明确科研目标 → 拆解研究计划 → 多专家协同推进 → 调用业务系统执行 → 持续反馈与优化**

> 一句话，开始推进科研任务：例如导师输入「帮我把这学期组里每个人安排到最合适的项目上」——科研大脑读取能力画像与负载 → 输出分配方案 → 导师确认 → 任务自动下发到每个人日历。

#### 人机协同三原则（科研版特有的底线设计）

1. **AI 建议、人决策**：投稿选择、招生录取、经费调配等关键决策必须人工确认，AI 只给「方案 + 依据 + 风险」；
2. **可溯源**：所有 AI 结论必须给出依据（文献引用/数据来源/规则条款），杜绝无依据断言进入科研流程；
3. **全程留痕**：AI 参与的每个环节记录日志，供机构审计与回溯。

## 六、AI 能力底座与数据中台

### 6.1 模型策略

- **底座**：国产大模型（GLM/DeepSeek/Qwen 等）+ 科研语料微调（学术写作、文献理解、代码生成、基金政策、审稿话语）；
- **RAG 溯源**：机构知识库（文献、规章、历史项目）做检索增强，回答必须带出处；
- **场景小模型**：查重预检、AIGC 检测、发票 OCR、意图分类等用轻量专用模型降本；
- **私有化选项**：模型本地化部署，满足涉密与数据敏感机构。

### 6.2 科研数据中台

- **核心实体**：人员（画像）、成果、项目、经费、文献、设备、日程、任务，以及他们之间的知识图谱关系（谁-做过什么-用了什么-产出什么）；
- **机构记忆库**：把散落在邮件、Word、微信里的组会纪要、申报书、结题报告沉淀为可检索资产，老师走了经验不走；
- **指标引擎**：ESI、学科评估、代表作、人均产出等指标口径内置，报表一键出。

### 6.3 集成生态

| 类别 | 对接对象 |
|---|---|
| 文献与情报 | 知网、万方、WoS、Scopus、arXiv、Crossref、专利库 |
| 写作与代码 | Overleaf、Word 插件、GitHub/Gitee |
| 校内系统 | 统一身份认证（CAS/OAuth）、教务（课表/成绩）、财务（预算/报销）、人事、图书馆、设备管理系统 |
| 沟通协作 | 企业微信、钉钉、飞书（消息推送与登录） |
| 期刊投稿 | 期刊官网投稿状态抓取/邮件解析、LetPub 类周期数据合作 |

## 七、部署、安全与合规

| 项 | 方案 |
|---|---|
| 部署模式 | ① SaaS 多租户（中小课题组快速上手）② 私有化（高校/院所，数据不出校）③ 混合云（敏感数据校内、算力上云） |
| 安全 | 等保三级、传输与存储加密、细粒度权限（院系/课题组/个人三级）、操作审计日志 |
| 信创 | 适配国产 CPU/OS/数据库，满足体制内院所采购要求 |
| 数据合规 | 《个人信息保护法》《数据安全法》：招生画像最小化采集、明示同意、限期删除；科研成果数据权属清晰（归机构与作者） |
| **学术红线（产品级内建）** | 见下 |

### 7.1 学术诚信红线设计（科研场景必须回答的问题）

- **AI 是教练不是枪手**：写作模块定位「润色、改写、辅导」，生成内容默认标注，引导用户披露；与期刊 AIGC 政策同步更新；
- **AIGC 检测与披露**：投稿前自查 AIGC 占比提示；伦理模块内置 AIGC 使用披露模板；
- **不碰代写**：不提供「输入题目输出整篇论文」的代写式功能，AI 输出必须锚定用户自己的数据、文献与实验记录（这也是与通用 ChatGPT 的本质区别：**有你的科研上下文，才帮你写你的论文**）；
- **数据真实性**：实验记录自动留痕，图像处理规范提示，从工具层面降低学术不端空间。

## 八、竞争分析

| 竞品/替代品 | 覆盖 | 智研星云的差异 |
|---|---|---|
| Zotero/EndNote/Mendeley | 文献管理 | 只有文献；我们文献只是入口，后接复现、写作、投稿 |
