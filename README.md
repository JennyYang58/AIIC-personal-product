## 📖 宣传册内容速览（6 页）

- **P1 封面** —— 「让科研，自己跑起来」：深蓝星图轨道 + 研擎 Claw 中枢球体，环绕学生平面 · 导师平面 · 机构平面三块卫星面板，底部为 MCP 连接器层。
- **P2 一个系统，三种身份** —— 研擎 Claw 中枢（八位 AI 员工、长在任务上、留痕可审）+ 三大平面：学生平面·启航流水线（免费）/ 导师平面·课题组驾驶舱（核心付费方）/ 机构平面·治理与资产（私有化）；四大能力「会分析 · 会决策 · 会执行 · 会交付」；MCP 集成战略：红海环节集成别人的（Zotero / Notion / GitHub / Overleaf），无人区环节自建（驾驶舱 / 套磁 / 经费 / 组会），流程数据留在本库。
- **P3 导师平面 · 课题组驾驶舱** —— 十大核心模块（项目管理 / 经费管理 / 成果管理 / 人员管理 / 文献资产 / 实验数据 ELN / 设备管理 / 招生管理 / 日程会议 / 统计分析）+ 决定机构是否买单的五道补强（AIGC 合规 / 数据血缘 / Rebuttal 响应 / 知识传承 / 经费审计）+ 五步协同闭环（发现问题 → 创建活动 → 开启托管 → 自动执行 → 复盘优化）「看得清 · 算得准 · 动得快」+ 机构平面（全院驾驶舱 / 经费红线 / 结题预警 / 权限矩阵 / 成果与 IP 库）。
- **P4 学生平面 · 启航流水线** —— 九步陪跑、一步一工件（选题定位 / 文献矩阵 / 可行性评估 / 零代码复现 / 结果图表 / 成稿排版 / 期刊匹配 / 投稿追踪 / Rebuttal 响应）；
  **研擎投稿 · 让成果更快被看见**：期刊智能匹配 / 审稿周期预测 / 投稿序列策略 / 审稿意见辅助 / 全链路洞察；
  **研擎 GEO · 让成果被 AI 发现和持续信任**：学术意图诊断 / 策略—执行—监控自动化 / AI 引用自迭代闭环 / 科研资产沉淀；
  信任设计三铁律：可见性三级 / 数据边界合同 / 不与考核挂钩。
- **P5 研擎 Claw · 实验室专家团队** —— 八位卡通 AI 员工：科研大脑（总控调度）/ 文献情报（检索·综述）/ 复现工程师（代码·实验）/ 写作教练（成稿·排版）/ 投稿顾问（期刊·策略）/ 招生匹配官（证据·筛选）/ 经费财务（预算·报销）/ 日程管家（会议·Deadline）；IDE 创作中心 × 扩展空间（轻应用 / Agent 专家 / 工作流 / Skill 技能，创建→发布、扩展→使用闭环）；一句话推进科研任务 + 权限边界与审计日志。
- **P6 封底** —— 深入科研 / 参与决策 / 推动执行 / 走向全球，官方网站与交流入口。

## 🎨 设计规范

- **配色**：白底 + 清华蓝（#1F419B）+ 浅蓝卡片（#F3F6FC / #E0E6F0）；封面与封底深蓝渐变（#16306F → #1F419B → #24499F）
- **字体**：Noto Sans SC / 微软雅黑，纯前端矢量绘制（封面星图、卡通人物、流程弧线均为内联 SVG，零图片依赖）
- **页面**：固定 A4（210×297mm / 794×1123px @96dpi），打印自动分页为 6 页
- ⚠️ 封底两个二维码为占位图案，正式发布前请替换为真实二维码

## 🖥️ MVP 应用（app.html）

**演示账号（点击登录页身份卡即可进入）：**

| 身份 | 姓名 | 能看到 | 看不到 |
|---|---|---|---|
| 🎓 本科生 | 李小白 | 启航流水线（九步一步一工件）、我的资产（三级可见）、复现体验 | 组内经费、导师管理会议、全院数据 |
| 🔬 研究生 | 陈博文 | 流水线、文献矩阵、复现工场、投稿中心（含 Rebuttal 响应）、报销、成长档案 | 他人负载、组内预算全景、套磁收件箱 |
| 👨‍🏫 导师 PI | 王振华 | 组盘 Board（红灯预警）、能力×负载、套磁证据匹配、经费审批、组内资产库（交接包）、审计日志 | 全院聚合数据 |
| 🏛️ 科研管理者 | 林 兰 | 机构驾驶舱、项目/经费监管、成果库、权限矩阵、预警中心 | 个人科研明细 |

- 跨角色联动：学生工件设为「对导师可见」→ 导师组内资产库立即可见；导师派任务 → 学生端同步；AI 调用全量进入审计日志
- 深链直达：`app.html?role=ug|grad|pi|admin`
- 纯前端单文件（零依赖、零构建），`localStorage` 持久化，可私有化部署到任意静态环境
