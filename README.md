## 🧩 产品体系（6 + 1）

- **研擎 Claw** —— 统一 AI 科研中枢：八位 AI 专家（科研大脑 / 文献情报 / 实验复现 / 写作教练 / 投稿顾问 / 招生匹配 / 经费财务 / 日程管家）
- **研擎 ERP** —— 项目 · 成果 · 经费 · 人员 · 日程，科研经营的操作内核
- **研擎慧眼** —— 文献情报与创新发现：AI 精读、知识图谱、Gap 诊断、选题评分
- **研擎 Lab** —— 零代码复现：论文解析 → 云端沙箱 → AI 结对编程 → 复现报告
- **研擎投稿** —— 期刊诊断（冲/稳/保）、发表托管、审稿追踪、被拒转投
- **研擎 Studio** —— 科研启航学院 + AI 写作/图表/翻译/汇报
- **研擎 Match** —— 套磁信解析、真实性核验、师生双向匹配（合规内建）

## 🔐 角色权限体系（RBAC）

| 模块 | 本科生 | 研究生 | 导师 PI | 管理者 |
|---|:-:|:-:|:-:|:-:|
| 工作台 | 个人 | 个人 | 课题组 | 机构级 |
| 启航学院 | ✓ | — | — | — |
| 文献库 | 基础 | 组内共享 | 组内共享 | — |
| 复现 | 引导式 | 完整 | 完整 | — |
| 投稿 | — | 我的 | 组内全部 | — |
| 套磁收件箱 | — | — | ✓ | — |
| 任务 | 我的 | 我的 | 分配全组 | — |
| 经费 | — | 我的报销 | 预算+审批 | 全院监管 |
| 日程 | 课程/讲座/组会 | +实验节点 | +管理会议 | 申报日历 |
| 机构数据 | — | — | — | ✓ |

治理原则：**最小可见**（学生不见管理会议与全院经费）、**字段级权限**（管理者只见聚合与异常）、**全程留痕**。

## 🛠️ 技术说明

- 纯前端单文件应用（零依赖、零构建），`localStorage` 持久化，支持私有化部署到任意静态环境
- 登录态与演示数据版本化管理，支持一键重置
- URL 参数直达身份演示：`app.html?role=ug|grad|pi|admin`
- 正式版路线：前端框架化 + 后端 API + 统一身份认证（CAS/OAuth）+ 私有化大模型（RAG 溯源）
